# تولدیاد (TavalodYad)

اپ آفلاین یادآوری تولدهای تقویم شمسی، با ذخیره‌سازی محلی Room و پشتیبان‌گیری/بازیابی JSON. تاریخ روز از ساعت دستگاه گرفته می‌شود و تبدیل تقویم به‌صورت Kotlin خالص و بدون کتابخانهٔ بیرونی انجام می‌شود.

## پشتیبان دستی
از منوی برنامه «پشتیبان در حافظه یا فایل» یا «پشتیبان در Google Drive» را انتخاب کنید. هر دو گزینه انتخاب‌گر فایل اندروید را باز می‌کنند؛ برای ذخیره در Drive از منوی سه‌خط انتخاب‌گر، Google Drive و حساب موردنظر را انتخاب کنید. برای بازیابی نیز «بازیابی از Google Drive» را انتخاب کنید و از منوی سه‌خط انتخاب‌گر به فایل JSON در Drive بروید. انتخاب‌گر ممکن است ابتدا فایل‌های گوشی را نشان دهد. در دسترس بودن Drive به برنامهٔ Drive، حساب و دستگاه بستگی دارد. پس از ذخیره، وضعیت همگام‌سازی را در برنامهٔ Drive بررسی کنید. هنگام بازیابی می‌توانید اطلاعات را اضافه یا جایگزین کنید. پشتیبان خودکار یا همگام‌سازی بین دستگاه‌ها وجود ندارد.

## دریافت APK با GitHub Actions
1. محتوای این پوشه را در مخزن GitHub (شاخهٔ `main` یا `master`) قرار دهید.
2. با push یا از تب Actions اجرای دستی `Android CI` را آغاز کنید.
3. artifact با نام `tavalodyad-apks` شامل APKهای debug و release خواهد بود.

Workflow از JDK 17 و Gradle 8.7 استفاده می‌کند و دستور `gradle build assembleDebug assembleRelease` را اجرا می‌کند. این پروژه در محیط تولید فایل build/کامپایل نشده است.
